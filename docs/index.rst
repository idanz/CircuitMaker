CircuitMaker Python API
=======================

Write Factorio circuits in Python, inspect their wiring, simulate signals,
and export blueprint strings from the CircuitMaker browser editor.

Start with :doc:`quickstart`, then browse the searchable API reference.
Signatures and member lists are generated from the same Python sources
used by the editor, including its graph and simulation extensions.
